# When it rains, it spills: interactive pieces

Two pages for a StoryMap about England's storm overflows, published with GitHub Pages.

- `storm-overflow-3d/`: an illustrative 3D storm overflow (not a real site, not a hydraulic model).
- `spill-drivers-map/`: why some catchments' overflows spill for longer.

Add `?embed` to either URL inside a StoryMap; the page then drops its own title.

Built with the ArcGIS Maps SDK for JavaScript 5.1. Data: Environment Agency (EDM storm overflow
annual returns, WFD Cycle 3 catchments), Met Office HadUK-Grid, Copernicus Land Monitoring Service,
British Geological Survey Hydrogeology 625k, ONS Census 2021. Contains public sector information
